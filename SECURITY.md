# Security policy

## Supported version

Security fixes target the latest code on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could put users at
risk. Use GitHub's private **Report a vulnerability** form in the repository's
Security tab. If that option is unavailable, contact
[@imarufov](https://t.me/imarufov) on Telegram with:

- the affected version or commit;
- clear reproduction steps;
- the expected impact;
- any suggested mitigation.

Do not include real user data, credentials, or destructive proof-of-concept
material. A public issue is appropriate for ordinary bugs that have no security
impact.
